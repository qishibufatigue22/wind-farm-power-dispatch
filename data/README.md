# 数据说明

完整竞赛数据不随仓库上传。请自行准备2024年中国研究生数学建模竞赛A题附件，并保留原始文件名。

| 文件 | 内容 | 使用模块 |
|---|---|---|
| 附件1-疲劳评估数据.xls | 100台风机、100秒载荷及参考疲劳指标 | 1.疲劳评估 |
| 附件2-风电机组采集数据.mat | 两个风场，每场100台风机、2000秒运行数据 | 2.载荷估算、3.功率调度 |
| 附件3-噪声和延迟作用下的采集数据.mat | 含噪声与延迟的运行数据 | 4.噪声与延迟处理 |
| 附件4-噪声和延迟作用下的采集数据.xlsx | 额外10台风机、300秒测试数据 | 4.噪声与延迟处理 |

将附件2放入本目录即可运行 `python scripts/evaluate.py`，或通过 `--data` 指定其他路径。

MAT结构为 `data_TS_WF -> WF_1/WF_2 -> WT`。每台风机的 `inputs` 为2000×2数组，第一列功率参考值（W），第二列风速（m/s）。评估脚本将功率转换为MW。

`sample/dispatch.json` 是人工构造的示例，供快速演示算法，不参与4000个时刻的实验指标统计。

历史实验脚本部分依赖 `all_data_2.npy` / `all_data_3.npy`：预期数组形状为 `(2,100,2000,9)`，最后一维依次是时间、功率指令、风速、主轴扭矩、塔架推力、输出功率、桨距角、低速轴转速、高速轴转速。相关中间文件不随仓库提供；推荐使用直接读取MAT的当前调度评估入口。
