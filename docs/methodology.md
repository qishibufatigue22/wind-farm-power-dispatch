# 模型与验证

## 1.疲劳评估

利用载荷幅值、S-N曲线和Miner规则衡量损伤。竞赛建模采用窗口及循环简化思路。保存的q_1.py实际使用历史最大最小值，而非固定滑动窗口；材料参数、Goodman修正和循环计数需进一步核查。该实验脚本没有纳入当前自动化验证。

## 2.载荷估算

保存MATLAB物理模型、空气动力模型及误差统计实验。扭矩与功率、转速相关，推力与空气密度、扫掠面积、风速及推力系数相关。实验脚本包含参数拟合，依赖MATLAB和原始MAT数据。

## 3.功率调度

当前入口直接读取MAT，将输入功率从W转为MW，以各机功率指令之和作为场站总任务，采用严格平均分配基准。代理目标是论文中的二次形式；物理疲劳模型尚未接入当前求解器。

求解器拒绝非法风速及不可行功率任务；利用KKT边际代价相等条件得到截断表达式，再二分搜索使总功率守恒。测试包括随机工况约束、相对基准改善、两风机网格对照、同风速与边界条件。数据评估另用SLSQP进行40个时刻对照。

总分累积为每秒代理代价相加一次，不对各时刻的累计值再次求和。计时仅包含核心算法。完整实验使用Python 3.12、NumPy 2.5.4、SciPy 1.18.1；其他依赖组合未逐一验证。

## 4.噪声与延迟处理

竞赛方案讨论卡尔曼滤波、AR预测、GM(1,1)及PSO。现存脚本是部分实验记录，不构成已经验证的完整鲁棒调度管线。PSO_2.py存在未定义目标函数及约束未接入等问题，不能直接作为可运行主入口；question4.py包含重复加噪声、固定延迟模拟等简化设定，不能据此认定已恢复真实信号。

竞赛结果表中的17.56%和17.93%与对应前后总数存在算术不一致，本仓库不将其列入已验证指标。需重新运行并统一测试协议后补充。
